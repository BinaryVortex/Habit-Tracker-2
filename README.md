# Legendary Habit Tracker

A simple and intuitive web-based habit tracker built with HTML, CSS, and JavaScript. Keep track of your daily habits, monitor your progress, and stay motivated!

## Features

- **Add Habits**: Easily add new habits to track.
- **Mark Completion**: Check off habits as completed, with date tracking.
- **Edit & Delete**: Modify or remove habits as needed.
- **Statistics**: View total habits, completed count, and completion rate.
- **Filter Habits**: Toggle to show only completed habits or all.
- **Clear Completed**: Remove all completed habits at once.
- **Export Data**: Export your habits to a CSV file for backup or analysis.
- **Import Data**: Import habits from a JSON file.
- **Persistent Storage**: Uses localStorage to save your data locally.

## How to Use

1. Open `index.html` in your web browser.
2. Enter a new habit in the input field and click "Add Habit".
3. Check the checkbox next to a habit to mark it as completed.
4. Use the options to edit, delete, filter, or clear habits.
5. Export your data by clicking "Export Habits".
6. Import data by selecting a JSON file.
